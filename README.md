# AKM Cinematic Dark Photography Portfolio

A modern cinematic photography portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Overview

AKM Cinematic Dark Photography Portfolio is a responsive photography showcase website designed to present photography work in a premium and immersive experience. The project focuses on cinematic visuals, smooth animations, category-based galleries, and a modern dark theme.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Cinematic dark user interface
* Photography category showcase
* Interactive image gallery
* Smooth animations and transitions
* Portfolio modal viewer
* Modern typography and layout
* Fast performance with Vite
* Clean and scalable component structure

## Categories

* Street Photography
* Portrait Photography
* Fashion Photography
* Event Photography
* Black & White Photography
* Cinematic Shoots

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Motion
* Lucide React

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Purpose

This project was developed as a personal portfolio project to showcase photography work through a modern web experience while demonstrating frontend development skills using React and TypeScript.
